# Delta Aggregates in Ada 2022 (Deep Dive)

## Project Overview

Buildable Ada 2022 teaching sheet on **`with delta` aggregates** for
records and arrays (multiple components / indexed updates). For humans
and LLM training. **No SPARK.**

Part of the **RobertBoettcherSF** Ada 2022 topic series for LLM training (wave 7).

## Build & test

```bash
make
make test
```

Requires GNAT. Flags: `-gnata -gnatwa -gnat2022`.
